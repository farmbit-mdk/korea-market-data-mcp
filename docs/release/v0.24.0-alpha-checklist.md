# v0.24.0-alpha Release Checklist

## Scope

Release goal:

```text
Read-only Kiwoom Quote MCP Alpha Launch Candidate
```

This release prepares documentation, examples, known limitations, and release notes for an alpha launch candidate. It does not expand runtime behavior.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
README quickstart and launch candidate sections are reviewed
CHANGELOG.md includes v0.24.0-alpha
docs/release/alpha-known-limitations.md exists
examples/README.md exists
examples contain no real credentials
examples contain no account/order/trading environment variables
Claude Desktop mock example exists
Cursor mock example exists
Claude Desktop Kiwoom local example is placeholder-only and advanced
Cursor Kiwoom local example is placeholder-only and advanced
provider-status lists public MCP tools
get_kiwoom_stock_quote is the only Kiwoom public quote tool
no account/order/balance/holdings/trading tools are added
fetch boundary remains in src/providers/kiwoom/transport.ts
unsupported features remain documented
```

## Safety

Confirm these defaults remain unchanged:

```text
MARKET_DATA_PROVIDER=mock
KIWOOM_ENABLE_REAL_API_CALLS=false
KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false
endpoint enabled default remains false
endpoint exposesPublicTool default remains false
real Kiwoom quote lookup remains disabled by default
Kiwoom real local verification remains explicit opt-in only
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
endpoint enabled default true
exposesPublicTool default true
real credentials in example files
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized credential storage
```
