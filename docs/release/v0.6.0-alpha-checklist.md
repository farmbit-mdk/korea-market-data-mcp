# v0.6.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Manual Token Verification Hardening
```

This is a hardening release. It does not add market data, account, order, trading, auto-trading, or recommendation features.

---

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
manual placeholder credentials are blocked
tests do not require real Kiwoom credentials
```

---

## Security

Before release, confirm:

```text
no real credentials in git
no token values in logs
no token values in test snapshots
no app key or secret key in errors
no raw token response included in error messages
```

---

## Scope Guard

Before release, confirm:

```text
no account tools
no order tools
no trading tools
no balance lookup
no holdings lookup
no auto-trading
no investment recommendation tools
no live quote, ETF, index, or chart lookup
```

---

## Fetch Boundary

Before release, confirm:

```text
fetch is isolated to src/providers/kiwoom/transport.ts
manual command uses the Kiwoom token client
unit tests use mocked transport only
KIWOOM_ENABLE_REAL_API_CALLS=false remains the default
```
