# v0.12.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Guarded Skeleton
```

This release registers a guarded read-only Kiwoom public quote tool skeleton. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
get_kiwoom_stock_quote is registered
real Kiwoom quote lookup remains disabled by default
guarded public quote tool returns blocked by default
blocked output does not include app key, secret key, or access token
public quote input schema excludes account/order/balance/holdings/trading fields
fetch boundary remains in src/providers/kiwoom/transport.ts
tests do not require real Kiwoom credentials
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
```
