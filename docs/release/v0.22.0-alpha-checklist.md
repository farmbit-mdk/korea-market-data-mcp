# v0.22.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Real Quote Local Activation Final Hardening
```

This release final-hardens the local/test-only activation guard for `get_kiwoom_stock_quote`. It does not enable public real Kiwoom quote lookup by default.
