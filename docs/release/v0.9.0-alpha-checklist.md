# v0.9.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Read-only Quote Manual Verification
```

This release adds a guarded manual quote verification workflow only. It does not add a public MCP quote tool.

---

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
endpoint disabled guard works
public MCP quote tool is not added
MCP tool registry remains unchanged
```

---

## Security

Before release, confirm:

```text
fetch remains isolated to src/providers/kiwoom/transport.ts
no credentials in git
no app key or secret key in logs/errors
no access token in logs/errors
quote output does not include token values
```
