# v0.14.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Guard Hardening
```

This release hardens `get_kiwoom_stock_quote` guard order, validation, response shapes, and redaction tests. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
get_kiwoom_stock_quote is registered
get_kiwoom_stock_quote returns blocked by default
mock/test success path returns ok with nested quote
symbol validation rejects edge cases
forbidden schema/runtime fields are absent or rejected
forbidden field values are not echoed
blocked/error/ok output excludes app key, secret key, access token, raw request body, and raw provider payload
fetch boundary remains in src/providers/kiwoom/transport.ts
tests do not require real Kiwoom credentials
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
```
