# v0.40.0-alpha Checklist

Release goal: Quant Research Data Bundle UX.

## Verification

- [ ] `npm run build`
- [ ] `npm test`
- [ ] `npm run kiwoom:setup:check`
- [ ] `git diff --check`
- [ ] `npm pack --dry-run`

## Data Scope

- [ ] `get_korean_market_data_context` returns `research_metrics` only as data-based calculations.
- [ ] Period return, high/low, latest close, average volume, and volume ratio are computed from `daily_charts[]`.
- [ ] Related index comparison fields stay `null` unless comparable period data is available.
- [ ] No user-facing mock market data fallback is introduced.

## Safety Scope

- [ ] No buy/sell judgment.
- [ ] No recommendation.
- [ ] No target price.
- [ ] No account access.
- [ ] No orders.
- [ ] No balance lookup.
- [ ] No holdings lookup.
- [ ] No trading or auto-trading.

## Notes

`research_metrics` are calculation-ready data payloads. Claude, GPT, Codex, or another MCP client is responsible for interpretation and analysis.
