# v0.21.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Real Quote Local Opt-in Activation
```

This release clarifies the local/test-only opt-in activation path for `get_kiwoom_stock_quote`. It does not enable public real Kiwoom quote lookup by default.
