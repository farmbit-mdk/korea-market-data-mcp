# v0.17.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Local Verification Hardening
```

This release hardens local-only verification docs and examples for `get_kiwoom_stock_quote`. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
local verification doc includes environment matrix
local verification doc includes blocked reason matrix
MCP request and response examples exist
.env.example keeps safe placeholders
.env.example keeps KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false
public real quote lookup remains disabled by default
docs/examples contain no real credentials
docs/examples contain no account/order/balance/holdings/trading/recommendation request fields
fetch boundary remains in src/providers/kiwoom/transport.ts
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
```
