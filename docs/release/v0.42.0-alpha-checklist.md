# v0.42.0-alpha Checklist

Release goal: Quant Research Examples and Prompt Pack.

## Scope

- Add example prompts for quant research data bundles.
- Add Claude Desktop examples for data-only market analysis.
- Add Codex/Cursor workflow examples for research notes and tables.
- Document data-only analysis boundaries.
- Keep provider capability unchanged.

## Included

- `docs/examples/quant-research-prompt-pack.md`.
- `docs/examples/claude-desktop-quant-research-examples.md`.
- `docs/examples/codex-cursor-research-workflows.md`.
- `docs/examples/data-only-analysis-boundaries.md`.
- README links to the example docs.
- Changelog and provider status notes.

## Explicitly Out Of Scope

- Buy/sell judgment.
- Recommendation.
- Target price.
- Return forecast.
- Portfolio recommendation.
- Rebalancing conclusion.
- Account access.
- Orders.
- Balance lookup.
- Holdings lookup.
- Trading.
- Auto-trading.
- User-facing mock market data fallback.

## Example Prompt Safety Checks

- [ ] Examples use data-summary wording.
- [ ] Examples include "투자 추천은 하지 말고" where useful.
- [ ] Examples avoid asking for a buy list, sell list, top picks, target price, or return forecast.
- [ ] Examples keep Claude/GPT/Codex as the interpretation layer.
- [ ] Examples do not ask for mock market data fallback.
