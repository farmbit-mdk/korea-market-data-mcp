# v0.8.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Quote Endpoint Mapping
```

This release documents and scaffolds endpoint mapping only. It does not enable live Kiwoom quote lookup and does not add a public MCP quote tool.

---

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
quote endpoint mapping document exists
real quote lookup remains disabled
public MCP quote tool is not added
MCP tool registry remains unchanged
mocked transport tests pass
```

---

## Security

Before release, confirm:

```text
fetch remains isolated to src/providers/kiwoom/transport.ts
no credentials in git
no credentials in logs
no token values in logs or errors
quote errors do not include raw request or response objects
```

---

## Scope Guard

Before release, confirm:

```text
no account access
no order tools
no balance lookup
no holdings lookup
no trading
no auto-trading
no investment recommendations
no live quote, ETF, index, chart, or realtime lookup
```
