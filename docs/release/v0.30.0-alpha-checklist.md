# v0.30.0-alpha Release Checklist

## Scope

Release goal:

```text
Official npm Alpha Publish
```

This release publishes the official npm alpha package using the `alpha` dist-tag.

It does not expand runtime behavior.

## Verification

Before publish, confirm:

```text
npm whoami passes
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
git diff --check passes
npm pack --dry-run passes
npm view package name pre-publish check completed
```

Publish command:

```powershell
npm publish --tag alpha
```

Do not run plain `npm publish`.

After publish, confirm:

```text
npm view korea-market-data-mcp name version dist-tags --json passes
npm view korea-market-data-mcp@0.30.0-alpha version --json passes
npm dist-tag ls korea-market-data-mcp passes
alpha dist-tag points to 0.30.0-alpha
latest currently points to alpha, but alpha install is still the required documented path
npm dist-tag rm korea-market-data-mcp latest attempted and failed with E400 Bad Request
npm install korea-market-data-mcp@alpha passes or is documented
audit reports 0 vulnerabilities
hosted proxy was not added
real Kiwoom quote lookup remains disabled by default
examples contain no real credentials
examples contain no account/order/trading environment variables
get_kiwoom_stock_quote public tool scope is unchanged
account/order/trading tools do not exist
fetch boundary remains in src/providers/kiwoom/transport.ts
```
