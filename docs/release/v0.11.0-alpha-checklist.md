# v0.11.0-alpha Release Checklist

## Scope

Release goal:

```text
Provider Compliance and Security Review
```

This release adds documentation and test boundaries only. It does not add public real provider functionality.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
SECURITY.md exists and is current
provider compliance docs exist
credential handling docs exist
public quote tool readiness checklist exists
public MCP quote tool is not added
public real Kiwoom quote lookup is not enabled
fetch boundary remains in src/providers/kiwoom/transport.ts
no credentials appear in logs, errors, fixtures, or docs
account/order/balance/holdings/trading/recommendation scope remains absent
```

## Explicitly Excluded

Do not include:

```text
public MCP quote tool
public real Kiwoom quote lookup
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
```
