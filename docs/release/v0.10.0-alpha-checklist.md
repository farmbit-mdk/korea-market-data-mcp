# v0.10.0-alpha Release Checklist

## Scope

Release goal:

```text
Harden Kiwoom quote manual verification workflow
```

This release is manual verification hardening only.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
manual quote command does not expose app key, secret key, or access token
manual quote command does not expose raw malformed quote response bodies
endpoint disabled guard blocks before token or quote transport calls
endpoint enabled/disabled policy is documented
public MCP tool registry remains unchanged
fetch remains isolated to src/providers/kiwoom/transport.ts
tests do not require real Kiwoom credentials
no real credentials are committed
```

## Explicitly Excluded

Do not include:

```text
public MCP quote tool
public real Kiwoom quote lookup
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
```

## Safety Notes

Endpoint mapping remains guarded:

```text
enabled:false by default
manualOnly:true
readOnly:true
requiresToken:true
exposesPublicTool:false
forbiddenScopes: account, order, balance, holdings, trading
```

Changing endpoint mapping to `enabled:true` must be reviewed separately and must not imply public MCP quote support.
