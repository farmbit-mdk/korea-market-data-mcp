# v0.13.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Mock Provider Integration
```

This release stabilizes `get_kiwoom_stock_quote` response shapes and validates mocked success flow. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
get_kiwoom_stock_quote is registered
get_kiwoom_stock_quote returns blocked by default
mock/test success path returns ok with nested quote
symbol validation rejects non-6-digit stock codes
forbidden schema fields are absent
blocked/error/ok output excludes app key, secret key, and access token
fetch boundary remains in src/providers/kiwoom/transport.ts
tests do not require real Kiwoom credentials
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
provider fallback to unrelated live data
```
