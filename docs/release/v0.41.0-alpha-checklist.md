# v0.41.0-alpha Checklist

Release goal: Quant Research Metrics Hardening.

## Scope

- Harden `research_metrics` edge cases.
- Document calculation formulas and null semantics.
- Add Claude Desktop data-summary examples.

## Included

- Empty/insufficient candle handling.
- Invalid close, high, low, and volume handling.
- Zero start price handling.
- No `NaN`, `Infinity`, or `-Infinity` in user-facing payloads.
- Related index comparison statuses for missing period data, insufficient candles, and period mismatch.

## Explicitly Out Of Scope

- Buy/sell judgment.
- Recommendation.
- Target price.
- Return forecast.
- Portfolio proposal.
- Rebalancing conclusion.
- Account access.
- Orders.
- Balance lookup.
- Holdings lookup.
- Trading or auto-trading.

## Verification Commands

- [ ] `npm run build`
- [ ] `npm test`
- [ ] `npm run kiwoom:setup:check`
- [ ] `git diff --check`
- [ ] `npm pack --dry-run`

## Research Metrics Edge Cases

- [ ] Empty candles return unavailable/null metrics.
- [ ] One candle keeps `period_return` null.
- [ ] Invalid close values do not produce numeric returns.
- [ ] Start price zero keeps `period_return` null.
- [ ] Missing volume keeps `average_volume` and `volume_ratio` null when no valid volume exists.
- [ ] Related index comparison stays null without comparable period data.
- [ ] Period mismatch keeps `asset_vs_index_return_diff` null.

## Documentation Checklist

- [ ] `period_return` formula documented.
- [ ] `volume_ratio` formula documented.
- [ ] `candle_count`, `average_volume`, high/low, and period date semantics documented.
- [ ] Data-only scope and no investment judgment scope documented.

## Claude Desktop Example Checklist

- [ ] Examples ask for data summaries.
- [ ] Examples avoid recommendation, buy/sell, target-price, or strategy-conclusion wording.
