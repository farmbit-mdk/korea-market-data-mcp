# v0.36.0-alpha Checklist

## Scope

Enable local Kiwoom quote verification for explicitly opted-in users.

This release does not add account access, orders, balance lookup, holdings lookup, trading, auto-trading, investment recommendations, hosted proxy behavior, or centralized data redistribution.

## Functional Checks

- package version is 0.36.0-alpha
- `get_kiwoom_setup_status` is registered as a read-only MCP tool
- `get_kiwoom_setup_status` does not request a token or quote
- `KIWOOM_ENV=real`, `KIWOOM_ENV=production`, and `KIWOOM_ENV=prod` resolve to production
- `KIWOOM_ENV=mock` resolves to mock
- setup check remains blocked by default
- setup check reports ready only when real API calls, public quote path, valid credentials, non-placeholder credentials, and provider/investment environments are aligned
- setup check ready `next_step` says to run token manual verification, then quote manual verification
- local quote path is enabled only when all explicit opt-in guards are valid
- `get_kiwoom_stock_quote` remains blocked by default
- `get_kiwoom_stock_quote` passes public exposure gate only for valid local verification env
- `get_korean_market_data_context` does not return mock quote/chart/index market values

## Safety Checks

- no real credentials in Git
- no access tokens in logs, docs, fixtures, tests, or snapshots
- no app key or secret key in errors
- no global fetch calls from provider logic outside the Kiwoom transport boundary
- no mock fallback introduced in real context payload
- No account access.
- No orders.
- No balance lookup.
- No holdings lookup.
- No trading.
- No auto-trading.
- No investment recommendations.
- No centralized data redistribution proxy.
