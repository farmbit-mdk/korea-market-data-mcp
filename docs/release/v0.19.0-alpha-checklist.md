# v0.19.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Smoke Test Result Capture
```

This release adds sanitized result capture documentation, a sample, and a GitHub sharing template for local-only smoke tests of `get_kiwoom_stock_quote`. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
docs/providers/kiwoom-public-quote-smoke-test-result-capture.md exists
docs/providers/templates/kiwoom-public-quote-smoke-test-result.md is updated
docs/providers/templates/kiwoom-public-quote-smoke-test-result.sample.md exists
docs/providers/templates/kiwoom-public-quote-smoke-test-github-report.md exists
README result capture section exists
.env.example keeps safe placeholders
.env.example keeps KIWOOM_ENABLE_REAL_API_CALLS=false
.env.example keeps KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false
public real quote lookup remains disabled by default
manual token and quote commands remain blocked by default
docs/templates/examples contain no real credentials
docs/templates/examples contain no tokens
docs/templates/examples contain no raw provider payloads
docs/templates/examples contain no account/order/balance/holdings/trading/recommendation scope
fetch boundary remains in src/providers/kiwoom/transport.ts
get_kiwoom_stock_quote remains registered as a guarded read-only tool
```

## Explicitly Excluded

Do not include:

```text
public real Kiwoom quote lookup by default
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized user credential storage
smoke test result storage containing credentials or raw provider payloads
```
