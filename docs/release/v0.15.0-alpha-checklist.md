# v0.15.0-alpha Release Checklist

## Scope

Release goal:

```text
Kiwoom Public Quote Tool Explicit Opt-in Verification
```

This release separates `get_kiwoom_stock_quote` real-path activation behind an explicit public quote opt-in. It does not enable public real Kiwoom quote lookup by default.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false appears in .env.example
default public quote tool path returns blocked
KIWOOM_ENABLE_REAL_API_CALLS=false blocks before token or quote clients
KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false blocks before token or quote clients
endpoint enabled/exposesPublicTool/readOnly guards block before token or quote clients
missing or placeholder credentials block safely

blocked/error/ok output excludes app key, secret key, access token, raw request body, and raw provider payload

```
