# v0.32.0-alpha Release Checklist

## Scope

Release goal:

```text
Real Market Data Context UX
```

This release improves the real Kiwoom setup and context experience without adding trading, account, order, balance, holdings, recommendation, hosted proxy, or mock fallback behavior for real context payloads.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:setup:check returns JSON status
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual uses default 005930 when no symbol is provided and is blocked by default when real API calls are disabled
git diff --check passes
npm pack --dry-run passes
```

## Real Market Data Context UX

Confirm:

```text
get_korean_market_data_context resolves natural-language stock and ETF queries for Kiwoom provider
real Kiwoom quote path uses existing guard flow
failed real quote lookup does not fall back to mock quote data
real chart context returns unavailable until implemented
real index context returns unavailable until implemented
provider_error and blocked statuses are explicit
```

## Kiwoom Setup Check

Confirm:

```text
kiwoom:setup:check reports real_api_enabled
kiwoom:setup:check reports public_quote_real_path_enabled
kiwoom:setup:check reports credentials_present
kiwoom:setup:check reports placeholder_credentials
kiwoom:setup:check reports kiwoom_investment_environment
```

## Explicitly Excluded

Do not include:

```text
mock fallback for failed real context lookup
hosted proxy
public real Kiwoom quote lookup by default
endpoint enabled default true
exposesPublicTool default true
public real path default true
real credentials in example files
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized credential storage
```
