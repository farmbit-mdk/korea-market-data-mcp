# v0.25.0-alpha Release Checklist

## Scope

Release goal:

```text
Package and Distribution Readiness
```

This release reviews package metadata, install/run documentation, examples, and distribution readiness. It does not expand runtime behavior.

## Verification

Before release, confirm:

```text
npm run build passes
npm test passes
npm run kiwoom:token:manual is blocked by default
npm run kiwoom:quote:manual is blocked by default
git diff --check passes
README install/run commands match package.json
examples command and args are reviewed
examples have no real credentials
examples have no account/order/trading environment variables
docs/release/distribution-readiness.md exists
docs/release/alpha-install-smoke-test.md exists
npm publish was not performed
hosted proxy was not added
get_kiwoom_stock_quote public tool scope is unchanged
fetch boundary remains in src/providers/kiwoom/transport.ts
unsupported features remain documented
```

## Package Metadata

Confirm:

```text
package name is korea-market-data-mcp
package version is 0.25.0-alpha
package license is MIT
package type is module
package main is dist/index.js
package bin maps korea-market-data-mcp to dist/index.js
package files include dist, docs, examples, .env.example, CHANGELOG.md, README.md, SECURITY.md, and LICENSE
scripts include build, start, test, kiwoom:token:manual, and kiwoom:quote:manual
```

## Safety

Confirm these defaults remain unchanged:

```text
MARKET_DATA_PROVIDER=mock
KIWOOM_ENABLE_REAL_API_CALLS=false
KIWOOM_ENABLE_PUBLIC_QUOTE_REAL_PATH=false
endpoint enabled default remains false
endpoint exposesPublicTool default remains false
real Kiwoom quote lookup remains disabled by default
mock provider is the recommended first setup path
Kiwoom real local verification remains explicit opt-in only
```

## Explicitly Excluded

Do not include:

```text
npm publish
hosted proxy
public real Kiwoom quote lookup by default
endpoint enabled default true
exposesPublicTool default true
real credentials in example files
account access
orders
balance lookup
holdings lookup
trading
auto-trading
investment recommendations
centralized data redistribution proxy
centralized credential storage
```
